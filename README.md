# Hotel La Palma Princess

Página web informativa dedicada al complejo hotelero **La Palma Princess**, situado en el municipio de Fuencaliente, en la isla de La Palma (Islas Canarias).

## Descripción

Este proyecto presenta información sobre el hotel La Palma Princess y la zona exclusiva para adultos **Esencia de La Palma**. La página está diseñada para ofrecer una experiencia visual atractiva mediante imágenes, navegación intuitiva y un diseño adaptado a dispositivos modernos.

## Características

- Encabezado con imagen principal de gran tamaño.
- Menú lateral desplegable con animaciones.
- Información detallada sobre el hotel.
- Sección dedicada a Esencia de La Palma.
- Área de contacto y redes sociales.
- Ventana emergente de cookies.
- Diseño responsive y moderno.
- Efectos y transiciones en elementos interactivos.

## Tecnologías utilizadas

- HTML5
- CSS3
- JavaScript

## Contenido

La página incluye información sobre:

- Instalaciones del complejo hotelero.
- Piscinas y zonas de ocio.
- Ubicación en Fuencaliente.
- Experiencias exclusivas para adultos.
- Información de contacto.
- Redes sociales oficiales.

## Objetivos del proyecto

- Practicar el desarrollo web con HTML, CSS y JavaScript.
- Diseñar una interfaz visual atractiva inspirada en páginas reales de hoteles.
- Implementar elementos interactivos como menús laterales y ventanas emergentes.
- Mejorar la experiencia de usuario mediante animaciones y diseño responsive.
